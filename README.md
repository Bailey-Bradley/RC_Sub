# RC Submarine

This contains all the code and resources for the RC Submarine (name pending). It will be a small aluminum hull submarine capable of surviving depths of up to 300ft and transmitting video of whatever creatures and structures it finds while down there!

## Proposed Features

- Rated for 300ft of depth
- Has 5 DoF of movement (missing strafe)
- Can sense temperature and pressure
- Can determine its current depth
- Has 45 minute battery life
- Can transmit 1080p video back to the pilot
